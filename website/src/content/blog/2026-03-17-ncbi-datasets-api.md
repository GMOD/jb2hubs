date: '2026-03-17'

  Accession pages move from the legacy E-utilities to the NCBI Datasets API,
  adding assembly stats, BUSCO completeness, gene counts, GC content and

---

We switched from the legacy E-utilities to the NCBI Datasets API and now display
rich metadata on accession pages: assembly stats (N50, contig counts), BUSCO
completeness, gene counts, GC content, and sequencing technology.
